# 🐍 Python Problem Solving Questions

A collection of **30 Python problem-solving questions** designed to strengthen programming fundamentals, logical thinking, and practical Python skills.

This repository contains beginner-to-intermediate level problems covering topics such as variables, conditions, loops, strings, lists, tuples, sets, dictionaries, functions, OOP, and JSON.

---

## 📚 Topics Covered

The 30 problems cover the following Python concepts:

- Variables & Data Types
- Integers
- Strings
- Lists
- Tuples
- Sets
- Dictionaries
- Conditional Statements
- `if`, `elif`, `else`
- `for` Loops
- `while` Loops
- Nested Loops
- Functions
- List of Dictionaries
- Dictionary Access
- Filtering Data
- Object-Oriented Programming (OOP)
- JSON
- JSON + Loops
- Nested JSON
- JSON Filtering
- Problem Solving & Logical Thinking
